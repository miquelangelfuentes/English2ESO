# English2ESO · Unit 2

Pàgina web estàtica de repàs de gramàtica anglesa per a alumnat de 2n d'ESO.

## Continguts

- Present Simple vs Present Continuous
- Stative verbs
- Tag questions
- Exercicis autocorrectius en tres nivells amb pistes i explicacions

## Desenvolupament local

No necessita dependències ni procés de compilació:

```bash
python3 -m http.server 8000
```

Obre `http://localhost:8000` al navegador.

## Publicació

Compatible amb GitHub Pages directament des de la branca `main`.
