# English2ESO · Unit 2

Pàgina web estàtica de repàs de gramàtica anglesa per a alumnat de 2n d'ESO, estructurada com un curs de vuit unitats.

## Estructura

- `index.html`: portada i índex de les vuit unitats
- `unit-2.html`: recursos interactius de la Unit 2
- `styles.css` i `app.js`: estils i interactivitat compartits

## Unit 2

- Present Simple vs Present Continuous
- Stative verbs
- Tag questions
- Exercicis autocorrectius en tres nivells amb pistes i explicacions

## Desenvolupament local

No necessita dependències ni procés de compilació:

```bash
python3 -m http.server 8000
```

Obre `http://localhost:8000` al navegador.

## Publicació

Compatible amb GitHub Pages directament des de la branca `main`.
